**Software Development**
- 4 years of experience starting with Python and JavaScript
- Full-stack web developer
- UI/UX design 
- Mobile and desktop application development

**Notable Projects**
- **Pqbler** - Advanced malware analysis tool inspired by Uncoverit. Upload suspicious files and extract source code without execution, detect token grabbers, viruses, C2 addresses, webhooks, and bot tokens. Currently in active development.
- **Controller** - Complete rewrite of Onii Selfbot with enhanced features. Hundreds of commands including server cloning, data extraction, moderator detection, permission bypass exploits, and automated actions across DMs and servers. Turkish localization in progress.
- **SMP** - Gobuster-style web enumeration tool. Scans URLs, analyzes source code, checks internet archives. Advanced development phase (more features coming soon).
- **Onii Selfbot** - One of Discord's largest selfbot projects (original version, 2+ years old)
- **Osinter** - Terabytes of Discord message data via automated AI analysis
- **451** - Comprehensive tool server
- **Lulz** - (.gg/lulz)
